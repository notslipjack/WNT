Theme color reference

Every theme is just these 9 variables. Set all 9 and you've made a new theme.

To add a new built-in theme: pick 9 hex values for the roles above, add a html.theme-yourname { --bg-deep: ...; ... } block in the <style> section, then add an <option> to the Theme dropdown with that value. That's it - everything on the page reads from these variables, nothing else needs to change.

Append vs. Replace

Append - each time you hit Generate, the new output gets added to the top of the box, so the newest thing you ran is always the first thing you see. Older entries stay below it. Good for building up notes across several generators in one case.

Replace - each Generate click clears the box first, so it only ever shows the most recent output. Good when you only care about the last thing you ran.

This is a global switch - it applies to every generator, not per-module. Reload the page to clear everything and start fresh.
